01 Logo Component — Dark / Light Swap
Dark Mode — "Glow" Variant
Gaseous Infusion — Bloom Active
Light Mode — "Refractive" Variant
Caustic Refraction — Clarity Mode
Dark Mode — Glow Protocol
Background: Deep Obsidian #0A0A0A
Effect: drop-shadow Fuchsia 24px + Cyan 48px
Animation: Pulse bloom, 3s ease-in-out
CSS class: .logo--glow
Light Mode — Refractive Protocol
Background: Bright White #FFFFFF
Effect: Subtle drop-shadow Cyan 8px only
Animation: None — static clarity
CSS class: .logo--refractive
Asset Requirements
Format: Transparent PNG (non-negotiable)
Min size: 512×512px source
Never: solid white / black bg
Always: float with min 20px clearance
Swap Mechanism
JS: matchMedia('prefers-color-scheme')
Attr: data-mode="dark|light" on :root
Transition: CSS filter 0.45s ease
Src swap: data-src-dark / data-src-light
/* ── Logo Component: Auto Dark/Light Swap ── */ // HTML markup — two sources, one element <img id="forge-logo" class="logo" data-src-dark="/assets/logo-glow.png" data-src-light="/assets/logo-refractive.png" alt="Forge AI" /> // JS: observer-based swap const logo = document.getElementById('forge-logo'); const swap = (isDark) => { logo.src = isDark ? logo.dataset.srcDark : logo.dataset.srcLight; logo.className = isDark ? 'logo logo--glow' : 'logo logo--refractive'; }; const mq = window.matchMedia('(prefers-color-scheme: dark)'); swap(mq.matches); mq.addEventListener('change', e => swap(e.matches)); /* ── CSS: glow vs refractive states ── */ .logo--glow { filter: drop-shadow(0 0 24px #F71BF8) drop-shadow(0 0 48px rgba(0,255,255,0.4)); animation: glowPulse 3s ease-in-out infinite; } .logo--refractive { filter: drop-shadow(0 0 8px rgba(0,150,220,0.3)); }

03 Neon-Glass CTA Button — Light-Emitting System
Hover each variant to activate glow layers
Primary · Secondary · Ghost
Primary CTA — 5-Layer Glow Architecture
Layer 1 — Inner Rim
inset 0 1px 0 rgba(255,255,255,0.2)
Top specular highlight simulates glass surface curvature.
Layer 2 — Base Refraction
inset 0 -1px 0 rgba(0,255,255,0.15)
Bottom caustic — cyan light refracting through the capsule base.
Layer 3 — Close Glow (12px)
0 0 12px rgba(247,27,248,0.5)
The immediate halo — most saturated, makes the button "emit."
Layer 4 — Mid Bloom (48px)
0 0 48px rgba(247,27,248,0.15)
Atmospheric diffusion — the glow as it travels through air.
Layer 5 — Ground Shadow
0 8px 24px rgba(0,0,0,0.4)
Physical grounding — prevents the button from floating unnaturally.
Glass Morphology — Surface Properties
Specular Sheen — ::before
Top 50% of button covered with
rgba(255,255,255,0.18) → transparent
Simulates a convex glass surface catching light.
Refraction Caustic — ::after
Bottom 30% inset cyan gradient.
Light passing through the capsule body collects at the base edge.
Fill — Transmissive Gradient
rgba(247,27,248,0.28) → rgba(0,255,255,0.18)
Never fully opaque — interior must feel gaseous, not solid.
Hover Amplification
On :hover: translate Y-3px + scale 1.02.
All glow layers intensify by ~2×. Conveys the button powering up.
Backdrop Filter
backdrop-filter: blur(12px)
The glass capsule blurs whatever is behind it — essential material behavior.
/* ── Forge AI CTA — Neon-Glass Button System ── */ .btn-primary { /* Typography */ font-family: var(--font-label); font-size: 14px; font-weight: 700; letter-spacing: 0.12em; text-transform: uppercase; color: #ffffff; /* Transmissive fill — never fully opaque */ background: linear-gradient(135deg, rgba(247,27,248,0.28) 0%, rgba(130,60,200,0.18) 50%, rgba(0,255,255,0.18) 100% ); backdrop-filter: blur(12px); border: 1px solid rgba(247,27,248,0.55); border-radius: 100px; padding: 16px 40px; /* 5-layer glow system */ box-shadow: inset 0 1px 0 rgba(255,255,255,0.2), /* rim specular */ inset 0 -1px 0 rgba(0,255,255,0.15), /* base caustic */ 0 0 12px rgba(247,27,248,0.5), /* close halo */ 0 0 48px rgba(247,27,248,0.15), /* mid bloom */ 0 8px 24px rgba(0,0,0,0.4); /* ground shadow */ transition: all 0.35s cubic-bezier(0.22, 1, 0.36, 1); overflow: hidden; position: relative; } /* Specular glass surface */ .btn-primary::before { content: ''; position: absolute; top: 0; left: 0; right: 0; height: 50%; background: linear-gradient(180deg, rgba(255,255,255,0.18) 0%, transparent 100%); border-radius: 100px 100px 0 0; } /* Refraction caustic */ .btn-primary::after { content: ''; position: absolute; bottom: 0; left: 10%; right: 10%; height: 30%; background: linear-gradient(0deg, rgba(0,255,255,0.18) 0%, transparent 100%); } /* Hover: power up */ .btn-primary:hover { transform: translateY(-3px) scale(1.02); border-color: rgba(247,27,248,0.85); box-shadow: inset 0 1px 0 rgba(255,255,255,0.28), inset 0 -1px 0 rgba(0,255,255,0.25), 0 0 18px rgba(247,27,248,0.75), 0 0 72px rgba(247,27,248,0.3), 0 12px 32px rgba(0,0,0,0.5); }
